Review where accounts are signed in and revoke access. Revoking stops a session from refreshing — see the note below on when it takes full effect.
Revocation is not instant. Signing out a session immediately blocks it from refreshing, but any access token it already holds stays valid until it expires (typically up to the JWT expiry window set in Auth settings). Plan for a short lag before a revoked device is fully locked out.
