Compliance · 13.5.3 / 12.5.11

HMDA LAR Export

Review and export this branch's Loan Application Register records with CFPB-coded values and per-row completeness checks.

Subset export — not a FIG submission file. This exports the LAR fields OriginFlow currently captures, with CFPB numeric codes, for internal QC and to feed a filing tool. A complete HMDA submission requires the full CFPB field set (including applicant demographics from hmda_demographics), a transmittal sheet, and validation against the current Filing Instructions Guide. Do not submit this file as-is.
