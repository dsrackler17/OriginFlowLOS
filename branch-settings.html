Branch SQL dump Every loan, borrower, condition, document, and chat message. Postgres-compatible .sql.gz (gzipped). ~30s for branches under 5K loans.
⊟
All loans · MISMO 3.4 bundle Every active and funded loan as a MISMO 3.4 XML file, zipped. Fannie/Freddie/Ginnie-compatible. Use this to migrate to another LOS.

⚐

⊘
Cancel branch & export everything Schedules a full data export, then closes the branch at the end of the current billing period. You'll get a download link emailed to the compliance contact 24 hours before close.
Compliance posture FACT SHEET
OriginFlow LOS is software, not a compliance officer. The information below describes how the platform behaves; it does not constitute legal or compliance advice. Your licensed lender remains responsible for federal and state compliance.
SubjectOriginFlow behavior
TRID waiting period Tracked per loan; LE/CD timestamps captured on send. Stage advance to funded is blocked until 3 business days after CD send (4 with the buffer above).
ECOA adverse action When a loan moves to denied, an ECOA-compliant adverse action notice is generated and queued for review. 30-day clock starts at denial timestamp.
HMDA LAR Every loan record contributes the HMDA fields it has. The LAR export above pre-fills 100% of fields the platform tracks; a few demographic fields require manual entry from the application.
RESPA fees / 0% tolerance Initial LE fee disclosure tracked. CD vs LE delta flagged on the loan if any fee crosses the 0% / 10% / unlimited tolerance line.
State licensing Configured under Licensed states. Loan creation and submission blocked for any property in an unlicensed state. Override requires an admin and writes a justification to the audit log.
Document retention Documents and audit logs retained for 7 years past loan closure (RESPA standard). Deletion requires admin with two-factor confirmation.
Encryption at rest AES-256, Postgres TDE. Document storage uses S3-equivalent SSE. Backups encrypted and stored cross-region.
Encryption in transit TLS 1.3 enforced. HSTS preloaded. Document URLs are short-lived signed URLs.
Access control Row-level security in Postgres scopes every query to branch_id. No cross-branch reads possible at the database layer.
SOC 2 Type 1 in progress. Type 2 observation period begins Q3 2026. Trust report at /trust when ready.
We use cookies for analytics. Helps us see which features people actually use. Nothing tied to a borrower or loan ever leaves your browser. Details in our Privacy Policy.
